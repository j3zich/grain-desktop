# <img src="src-tauri/icons/icon.png" width="32"> Grain

Windows desktop app for a [Silo](https://github.com/Silo-Server/silo-server) server that plays video in mpv under the Silo web UI.

Download the [latest installer](https://github.com/j3zich/grain-desktop/releases/latest/download/Grain_x64-setup.exe).

Run `pnpm setup-lib` once to download mpv into `src-tauri/lib`.

`Ctrl+,` opens the settings.

mpv reads `mpv.conf` from `%LOCALAPPDATA%\com.j3zich.grain`.
